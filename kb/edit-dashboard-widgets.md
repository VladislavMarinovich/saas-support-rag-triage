# Editing widgets and layout on an existing dashboard

You can change a dashboard after building it: adjust what each widget measures, rearrange the layout, or remove widgets you no longer use. Editing requires **Analyst** or **Admin** — Viewers see PF002 when they try to save.

## Changing what a widget measures

1. Open the dashboard and click the widget menu (**⋯**) on the card you want to change.
2. Choose **Edit**.
3. Change the source (Google Ads, Meta Ads, Google Analytics, HubSpot, Salesforce, Mailchimp), the metric, or the date range.
4. Adjust filters and breakdowns — for example, break spend down by campaign.
5. Save. The widget reloads with the new query; other widgets are untouched.

If the widget returns DB004 after switching sources, the new source does not provide that metric — pick one it does, or use a second widget instead.

## Rearranging, resizing, and removing widgets

- **Move** — drag a widget by its header to a new position; the layout saves automatically.
- **Resize** — use the widget menu (**⋯**) to change its size.
- **Rename** — a clear title ("Paid spend by campaign") makes a dashboard readable months later.
- **Remove** — delete from the widget menu. This removes it from the dashboard only; the underlying data is untouched.

If adding a widget returns DB005, the dashboard is already at its limit — split it by theme instead. Changes are visible to everyone with access to the dashboard as soon as you save, so coordinate with your team before reworking a shared page. If a saved change does not appear after a reload, contact support with the dashboard name.
